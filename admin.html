Connect the database first

This admin page needs Supabase settings in config.js. Follow the steps in the README:

  1. Create a free project at supabase.com.
  2. In the SQL Editor, run supabase/schema.sql, then supabase/seed.sql.
  3. Add each owner: Authentication, Users, Add user. Then add their email to the admins table.
  4. Paste the Project URL and the anon public key into config.js.
